A highly configurable overlay for learning programmable keyboards. KeyAura reads supported keyboards directly and keeps the visual interface lightweight, adaptable, and out of your way.

KeyAura listens to supported QMK keyboard event transports: layer changes and physical key presses are read directly from the connected keyboard, rather than inferred from application text. The current Voyager adapter uses Oryx Raw HID.

Created as a vibe-coded experiment with Claude and Codex.
